Załącznik nr 6 do Model „Agencja Pracy Incydentalnej”
INFORMACJA DOTYCZĄCA DZIAŁALNOŚCI Agencji Pracy Incydentalnej
Dewiza Agencji Pracy Incydentalnej „Ułatwimy znalezienie pracy przez każdego”
1. API to forma innowacji społecznej., stanowiąca inkubator pracy dla osób
prowadzących nierejestrowaną działalność gospodarczą.
2. API dzięki swojej aktywności i kontaktom w różnych obszarach, poprzez
skoncentrowanie się na potencjale osoby i przy uwzględnieniu potrzeb podmiotów
trzecich do możliwości oraz uwarunkowań sytuacji życiowej osoby, stwarza
potencjalne warunki i daje jej szanse upodmiotowienia na rynku pracy
(samozatrudnienie).
3. Podmioty współpracujące z API ponoszą pełną i wyłączną odpowiedzialność za
swoje działania.
4. API umożliwia kontakt pomiędzy konkretną osobą prowadzącą nierejestrowaną
działalność gospodarczą a podmiotem/osobą mogącym zlecić takiej osobie do
wykonania określone usługi.
5. Model API koncentruje się na potrzebach i oczekiwaniach głównie „pracownika
samozatrudnionego” umożliwiając mu kontakt z podmiotem/osobą mogącym
potencjalnie skorzystać z jego usług.
6. Osoby prowadzące nierejestrowaną działalność gospodarczą wykonują wyłącznie
zadania
i czynności, które nie wymagają rejestracji jako czynny podatnik VAT oraz nie
wymagają pozwoleń, licencji oraz obowiązku prowadzenia kasy fiskalnej.
7. Wynagrodzenie za wykonaną pracę jest wypłacane osobie świadczącej usługi
bezpośrednio przez podmiot/osobę je zlecającą. Dokonując rozliczeń, strony mogą
skorzystać z druków, wzorów, draftów udostępnionych im przez API.
8. Na żądanie podmiotu/osoby zlecającego prace osoba prowadząca nierejestrowaną
działalność gospodarczą wystawia rachunek.
9. Żadne z podejmowanych przez API działań zmierzających do umożliwienia kontaktu
osoby prowadzącej nierejestrowaną działalność gospodarczą z podmiotem/osobą
mogącym udzielić jej zlecenia lub związane z wykorzystaniem dokumentów, o
których mowa w pkt powyżej, nie wiążą się z odpłatnością któregokolwiek z tych
podmiotów.
